# Sales Data Pipeline & Analysis

## Overview
This project demonstrates a simple data pipeline where sales data is ingested, processed, and analyzed using Python.

## Workflow
- Load data from CSV
- Perform data cleaning
- Generate insights
- Visualize trends

## Tech Stack
- Python
- Pandas
- Matplotlib

## Key Insights
- Total sales calculation
- Region-wise performance
- Product-wise performance

## Files
- Sales_data.csv → raw data
- sales_data_pipeline.ipynb → analysis notebook
